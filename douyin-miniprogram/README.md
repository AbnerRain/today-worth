# 摸力全开抖音小程序

这是《摸力全开》的抖音小程序版本，和根目录的微信小程序版本分开维护。

## 导入方式

使用抖音开发者工具导入当前 `douyin-miniprogram/` 目录。目录内的 `project.config.json` 已配置抖音 AppID 和抖音原生小程序工程类型。

## 平台边界

- 微信版本：根目录 `miniprogram/`，文件使用 `.wxml`、`.wxss`，调用 `wx.*`。
- 抖音版本：当前目录，文件使用 `.ttml`、`.ttss`，调用 `tt.*`。
- 两个平台的本地缓存相互隔离，微信中的历史记录不会自动出现在抖音版本中。
- 抖音分享模板、数据分析事件和后台隐私配置需要在抖音开放平台重新配置。

## AppID

当前配置中的 `tt69ce1f73f7b4b3ee01` 来自本地抖音项目配置。提交审核前，请在抖音开放平台确认它属于《摸力全开》正式小程序。
