# 摸力全开

这是《摸力全开》的微信原生小程序与 H5 原型。它把工作日里的零碎时间换算成金额，让用户知道自己上班的每一分钟值多少钱。

当前视觉方向：年轻职场漫画风。界面采用粗描边、错位阴影、漫画网点、薄荷绿、亮黄和电光蓝；保留产品幽默感，并让计时、收益与分享战报都更有游戏感。

当前版本为 `v1.0.5`，历次更新说明见 [版本记录](CHANGELOG.md)。

## 怎么打开

根目录 H5 仅作为同步预览，产品实现以 `miniprogram/` 为准。直接打开 `index.html` 即可预览；如果浏览器限制本地文件访问，也可以在当前目录启动静态服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 微信小程序接入

仓库已包含原生微信小程序，目录为 `miniprogram/`，根目录 `project.config.json` 已配置正式 AppID，可直接用于微信开发者工具导入。

由于主体类型为个人，小程序采用原生页面，不依赖 `web-view` 和 H5 业务域名。当前已迁移首页计时、工资设置、本地存储、统计、成就、结算战报和微信好友分享。完整上线步骤见 [微信小程序接入准备清单](docs/WECHAT_MINIPROGRAM_ONBOARDING.md)。

## 当前覆盖

- 工资设置：月薪、工作天数、每日工时，可保存并重算时薪。
- 首页主流程：支持带薪拉屎、带薪吃饭、带薪睡觉和一个自定义模式，展示专属动画、实时计时、实时收益、钞票金币雨和当前模式的独立今日累计。
- 活动战报：三种核心活动拥有独立结算画面，展示本次时长、收入和今日累计，并支持微信好友分享。
- 带薪愿望单：提供饮品、餐食、电影等六种目标，按累计收入展示赞助进度。
- 数据统计：支持日、周、月、职业生涯四个周期，并分别展示四类活动贡献。
- 成就系统：拉屎、吃饭、睡觉三条履历线，共 18 枚成就及独立成就图片。
- 稳定与增长：支持中断计时恢复、结算撤销、单条记录删除、分享金额自适应和匿名渠道分析。

## 自动化测试

无需安装第三方依赖，使用 Node.js 内置测试运行器：

```bash
npm run test:release
```

该命令会依次检查发布配置、版本号、页面与资源完整性、主包大小、小屏布局约束、分享卡片、工资换算、独立统计、成就数据、钞票雨和结算逻辑。

单独执行压力测试：

```bash
npm run test:stress
```

## 界面原则

- 第一屏优先服务最高频动作：查看当前收益、开始计时、结束生成战报。
- 顶部保留工资换算结果，帮助用户理解“时间单价”。
- 底部 Tab Bar 固定为首页、统计、成就三个入口。
- 图标使用统一线性 SVG 和代码绘制的漫画图形，避免结构性 emoji 造成平台显示差异。
- 所有主要触控区不低于 44px，适配小屏手机宽度。
- 快捷入口使用本地存储保存修改，刷新页面后仍保留用户编辑的数据。
- 分享按钮优先调用系统分享能力，不支持时复制分享文案；也提供单独的复制入口。
