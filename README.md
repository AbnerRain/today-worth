# 今天值多少钱 Demo

这是《今天值多少钱》的轻量 H5 原型，用来先验证微信小程序的核心界面和交互。

当前视觉方向：年轻职场漫画风。界面采用粗描边、错位阴影、漫画网点、薄荷绿、亮黄和电光蓝；保留产品幽默感，并让计时、收益与分享战报都更有游戏感。

## 产品规格

后续开发按 [产品规格说明](docs/SPEC.md) 推进。新增功能前先确认是否符合 spec；如果方向变化，先更新 spec 再改代码。

## 怎么打开

直接打开 `index.html` 即可预览；如果浏览器限制本地文件访问，也可以在当前目录启动静态服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 当前覆盖

- 工资设置：月薪、工作天数、每日工时，可保存并重算时薪。
- 首页主流程：可选带薪拉屎、带薪用膳、带薪睡觉三种模式，并显示对应主题、实时计时、实时收益、随机文案和当前模式的独立今日累计。
- 活动战报：展示本次活动、时长、收入、今日累计，支持分享战报和复制分享文案。
- 时间账本：通勤、咖啡、会议、加班等快捷入口，可修改名称、类型、数值和反馈文案。
- 数据统计：日、周、月、职业生涯四个周期。
- 成就系统：第一泡、连续七天、收益破千、厕所 VIP 等。

## 界面原则

- 第一屏优先服务最高频动作：查看当前收益、开始计时、结束生成战报。
- 顶部保留工资换算结果，帮助用户理解“时间单价”。
- 底部 Tab Bar 固定为首页、统计、成就三个入口。
- 图标使用统一线性 SVG 和代码绘制的漫画图形，避免结构性 emoji 造成平台显示差异。
- 所有主要触控区不低于 44px，适配小屏手机宽度。
- 快捷入口使用本地存储保存修改，刷新页面后仍保留用户编辑的数据。
- 分享按钮优先调用系统分享能力，不支持时复制分享文案；也提供单独的复制入口。
