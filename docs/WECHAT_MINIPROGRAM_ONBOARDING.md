# 微信小程序上线清单

本文记录《摸力全开》从开发版到微信小程序正式版的上线工作。

## 已确认信息

- 主体类型：个人。
- 小程序名称：摸力全开。
- AppID：已写入根目录 `project.config.json`。
- 技术路线：微信原生小程序，不使用 `web-view`，不依赖 H5 业务域名。

若后台提示名称需要补充资质，应先核对已审核名称与代码配置是否一致，不要提交无关行业资质。

## 已完成的开发内容

- 原生首页：时薪换算、拉屎、吃饭、睡觉和自定义计时模式。
- 独立统计：每个模式只统计自己的次数、时长和收益。
- 本地数据：工资设置、计时记录和愿望目标保存在用户手机中。
- 原生统计页：支持日、周、月和生涯汇总。
- 原生成就页：按三种活动计算解锁进度。
- 结算战报：完成计时后展示独立结算卡片。
- 微信分享：可从首页战报、统计页和成就页分享给微信好友。

## 现在需要在微信后台完成

1. 补齐小程序头像、介绍和服务类目。
2. 检查“摸力全开”名称是否通过审核，并确认后台名称与代码配置一致。
3. 下载并安装微信开发者工具，用管理员微信扫码登录。
4. 导入仓库根目录，确认 AppID 自动识别正确。
5. 在仓库根目录运行 `npm run test:release`，通过后再在开发者工具中逐项测试首页、计时、设置、统计、成就和分享。
6. 点击“预览”，在真实微信中至少完成一次拉屎、吃饭和睡觉计时。
7. 点击“上传”，本次版本号填写 `1.0.4`，备注填写“恢复活动动画与虚拟钞票雨，新增上线自动检查”。
8. 前往小程序后台的版本管理，将上传版本设为体验版并邀请体验成员测试。
9. 根据后台实际提示补齐隐私保护指引、用户隐私说明和审核材料。
10. 确认体验版没有阻塞问题后提交微信审核。

## 首版审核说明建议

本小程序是一款个人效率与时间记录工具。用户可自行填写月薪、工作天数和每日工时，将拉屎、吃饭、睡觉等工作日休息片段换算成时间价值，并在本机查看统计与成就。当前版本不要求登录，不收集手机号、位置、通讯录或工资数据，所有业务数据仅保存在用户本机。

## 暂未接入

- 微信登录和跨设备数据同步。
- 好友关系与互加好友。
- 服务端数据库和云函数。
- 分享海报图片与小程序码。

好友互加不能只靠分享按钮完成，后续需要接入微信登录、用户授权、邀请关系记录和服务端数据存储。这部分应在首版通过审核后单独开发。
