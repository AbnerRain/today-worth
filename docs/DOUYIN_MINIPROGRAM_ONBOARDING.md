# 抖音小程序接入清单

本文记录《摸力全开》抖音版本的工程边界和上线前检查项。

## 工程目录

- 微信版本：`miniprogram/`
- 抖音版本：`douyin-miniprogram/`
- 抖音版本可以直接使用抖音开发者工具导入 `douyin-miniprogram/`。

## 已完成的代码迁移

- 页面结构由 WXML 转为 TTML。
- 页面样式由 WXSS 转为 TTSS。
- 微信模板指令 `wx:if`、`wx:for` 等转换为抖音模板指令 `tt:if`、`tt:for`。
- 存储、弹窗、跳转、TabBar、Canvas、文件系统和数据分析调用迁移到 `tt.*` 命名空间。
- 首页分享文案改为“分享给抖音好友”。

## 上线前必须在抖音后台完成

1. 确认 AppID、主体和服务类目。
2. 填写抖音版本的隐私保护指引和用户协议。
3. 配置分享模板并验证分享参数回流。
4. 创建并绑定数据分析事件：计时开始、完成、撤销、统计查看、成就查看和分享打开。
5. 使用抖音开发者工具执行代码质量检查和审核预检。
6. 在 Android、iOS 真机完成首次引导、工资设置、三种计时、自定义行为、结算、钞票雨、金币雨、成就和分享回流测试。
7. 上传体验版，确认体验版无阻断问题后提交审核。

## 注意事项

微信和抖音版本使用不同的本地缓存空间，不能把微信用户数据视为抖音版本的迁移数据。当前产品不依赖账号系统和服务端，因此两端记录默认各自保存。
